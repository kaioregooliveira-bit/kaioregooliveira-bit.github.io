# Portfólio Web — Kaio Rêgo Oliveira

Site estático responsivo, pronto para publicação.

## Arquivos
- `index.html` — página principal
- `styles.css` — identidade visual, layout e responsividade
- `script.js` — filtros, menu mobile, animações e modal de projetos
- `assets/` — fotos, mapas, fundo topográfico e PDF do portfólio

## Publicar com um link

### Netlify (mais simples)
1. Acesse https://app.netlify.com/drop
2. Arraste a pasta `kaio_portfolio_site` ou o conteúdo extraído do ZIP.
3. O Netlify cria um endereço público imediatamente.
4. Em Domain Management, você pode trocar o subdomínio ou conectar um domínio próprio.

### Vercel
1. Crie um repositório no GitHub e envie esta pasta.
2. Importe o repositório em https://vercel.com/new
3. Framework Preset: `Other`.
4. Build command: deixe vazio.
5. Output directory: deixe vazio / raiz.

### GitHub Pages
1. Envie os arquivos para um repositório público.
2. Settings > Pages > Deploy from a branch.
3. Escolha `main` e `/ (root)`.
